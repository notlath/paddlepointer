# 10 — Make History rows clearly actionable

**What to build:** Users can tell that a completed Game has a summary and can open it through an explicit, adequately sized action rather than discovering that only the winner badge is clickable.

Origin: UI/UX audit finding U-11, limited to History.

**Blocked by:** None (can start immediately)

**Status:** completed

- [ ] Every History item with a summary exposes an explicit View Summary action
- [ ] The action has an accessible name that identifies the relevant Game
- [ ] The action meets the minimum touch-target size on mobile
- [ ] Keyboard focus order follows the visual order of each History item
- [ ] Winner, final score, date, and source remain readable without being mistaken for controls
- [ ] Opening a summary preserves the existing role restrictions and return path to History
