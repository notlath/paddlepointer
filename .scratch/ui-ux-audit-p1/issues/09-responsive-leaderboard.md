# 09 — Make Leaderboards readable without hidden horizontal content

**What to build:** Players, Visitors, and staff can understand ranking, wins, losses, percentage, differential, and minutes on a phone without discovering columns through an unlabelled horizontal scroll area.

Origin: UI/UX audit finding U-11, limited to Leaderboards.

**Blocked by:** None (can start immediately)

**Status:** completed

- [ ] Leaderboard rows remain understandable at 320px and 375px widths
- [ ] Player or team identity and rank remain visible while reviewing secondary statistics
- [ ] If horizontal scrolling remains, the interface visibly indicates that more columns are available
- [ ] Column and value relationships remain available to screen readers
- [ ] Positive and negative differentials remain distinguishable without relying on color alone
- [ ] Desktop table density and ranking order remain unchanged
- [ ] Empty and partially populated Leaderboards retain clear explanatory states
