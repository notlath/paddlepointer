## Recommended but not planned

- **Finish the token contract** (open tickets `.scratch/ui-ux-audit-p3/issues/17`, `18`):
  139 legacy brand-variable references and 59 raw colors remain outside `:root`; 5 red
  tests already describe the target. This is the biggest remaining consistency debt;
  it is already specified, so no new plan was written.
- **Delete `styles-old.css`** (91 KB): referenced by no HTML, JS, PHP or PS1 file.
  One-line cleanup; confirm with the owner that it isn't a manual rollback copy.
- **QR code via a third party**: `renderPlayerAccessCard()` sends the player-page URL
  (a LAN address) to `api.qrserver.com`. Low risk, but a local QR generator would remove
  the external dependency and work offline at venues.
- **Stale ticket statuses**: `.scratch/ui-ux-audit-p0/issues/01–04`, `p2/01`, `p2/09` say
  `ready-for-agent`, but their outcomes are in the code (sign-in `<form>` + `aria-invalid`,
  radio-backed segments, semantic tokens, `renderDestructiveConfirmation`). Mark them done
  so they aren't re-worked.
- **Collapsing disclosures**: `.format-estimate` and `.round-group` `<details>` lose their
  open state on every re-render (same issue plan 004 solves for its new disclosure).
- **Breakpoint sprawl**: 11 distinct width breakpoints (380, 520, 560, 700, 760/761,
  767/768, 800, 900, 980/981, 1399/1400). Consolidating to ~4 is worth doing together
  with the token contract, not before.
- **Tournament Format Review**: 5 stats in a 2-column grid leave an orphan; "Advanced
  format calculations — 0 min" reads as a broken value when empty.
- **Dashboard empty state** says "no matches" four times (Next Match, Live Courts,
  Upcoming, Recent). Low priority.

## Findings considered and rejected

- **Live Board: empty band between tabs and court grid at ≥1400×900.** Caused by
  `.live-tv-mode .live-score-grid { align-self: center }`, documented in a comment as
  intentional, and part of the uncommitted Live Board revamp. Revisit once that work lands.
- **Mobile layout, labels, headings**: automated sweep at 390px over home, setup,
  tournament, live, people, profile, rules and history found no horizontal overflow,
  no clipped text, no unlabeled controls, one `<h1>` per view. Earlier audit tickets
  already covered this well.
- **A shared `renderRefreshButton()` helper**: would break `tests/data-refresh.test.js`,
  which matches the literal `data-action` in the markup; plan 005 changes labels in place instead.
- **Sign-in portals**: governed by `DESIGN.md` §1–7 and already revised
  (`design-plans/paddlepoint-sign-in-revitalization.md`); nothing new found.
